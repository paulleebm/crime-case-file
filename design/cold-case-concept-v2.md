# 미제 사건 수사 게임 — 기획서 V2 (새 사건 「하송리 정미소 사건」)

작성 2026-10-22 / 상태: 기획 검토용 초안
작업 위치: 로컬 git 브랜치 `cold-case`. 이전 안은 [V1](cold-case-concept-v1.md), 두 안의 비교는 이 문서 10절.

## 0. 이 게임이 주려는 경험

1. **컷신을 다 보고 나면 머릿속에 물음표만 가득하다.** "밀실인가?", "죽은 사람 집에 누가 불을 켰지?", "돈이 왜 늘어나?"
2. **그 물음표를 내가 직접 확인해 본다.** "CCTV는 없었나?", "지문은?", "통화 기록은?", "개는 안 짖었나?" 떠오르는 대로 시켜 볼 수 있다.
3. **조사할수록 더 이상해지는 구간이 있다.** 거짓말하는 사람이 나오고, 시간이 맞지 않는다. 미궁에 빠질 수 있다.
4. **가닥이 잡히는 순간이 온다.** 물음표들이 하나씩 "아, 그래서였구나"로 바뀐다.
5. **다 풀고 나면 납득된다.** 말도 안 되는 일은 하나도 없었다. 평범한 사람들이 평범한 이유로 한 일과 우연이 한 밤에 겹쳤고, 당시에는 정보가 부족했을 뿐이다.

추리 게임보다 **수사 게임**이다. 정답을 맞히는 게임이 아니라, 수사 방향을 잡는 게임이다. 방향을 잘 잡으면 빨리 끝나고, 잘못 잡으면 오래 헤맨다. 둘 다 재밌어야 한다.

## 1. 스토리를 만드는 규칙

이 사건과 다음 사건 모두에 적용한다.

1. **범인은 천재가 아니다.** 겁에 질린 평범한 사람이다. 트릭을 설계하지 않는다. 범인이 한 일은 단순하다.
2. **이상한 점은 대부분 범인이 만든 것이 아니다.** 범인과 상관없는 사람들이 각자의 사정으로 한 일, 그리고 우연이 만든다.
3. **우연은 하나하나 흔한 일이어야 한다.** 눈이 그 시각에 내리기 시작했다, CCTV 시계가 틀려 있었다 같은 것. "이럴 확률이 얼마냐"는 말이 나오는 우연은 쓰지 않는다.
4. **같은 밤에 두 방문이 겹친 것에는 이유가 있다.** 우연처럼 보이지만 피해자가 같은 날 두 사람에게 같은 기한을 통보했기 때문이다. 나중에 알면 "그래서 그날이었구나"가 된다.
5. **컷신의 물음표 하나에 답 하나.** 모든 물음표는 게임 안에서 확인할 수 있는 자료나 진술로 풀린다. 풀리지 않는 떡밥은 남기지 않는다.
6. **당시 수사가 실패한 이유도 납득돼야 한다.** 무능해서가 아니라, 그럴듯한 오판 하나가 다음 오판을 불렀다.

## 2. 사건 개요 (플레이어에게 보여 주는 것)

- 2008년 12월 25일 아침, 가상의 남오군 하송리.
- 마을 정미소를 운영하며 혼자 살던 한명수(61)가 정미소에 붙은 자기 집 거실에서 숨진 채 발견됐다.
- 머리를 둔기로 맞았다. 흉기는 책상 위에서 문진으로 쓰던 놋쇠 저울추였다.
- 한명수는 마을 사람들에게 돈을 빌려주고 이자를 받았다. 원망하는 사람이 많았다.
- 수사는 1년 넘게 이어졌지만 아무도 기소되지 않았다.

## 3. 시작 컷신 — 물음표 여섯 개

형식: 종이 테마 위에 그림 한 장, 글은 한 문장씩 줄을 바꿔 나온다. 클릭하면 다음 장, 건너뛰기 가능.

1. **2026년, 경찰서 문서고.** 누렇게 바랜 기록 상자.
   > 2008년 크리스마스 아침.
   > 시골 마을의 정미소 주인이 집 안에서 숨진 채 발견됐다.
   > 17년이 지난 지금도, 범인은 잡히지 않았다.
2. **눈 덮인 집.**
   > 현관문은 잠겨 있었다.
   > 밤새 내린 눈 위에는 발자국 하나 없었다.
3. **전화기.**
   > 그는 숨지기 직전, 119에 전화를 걸었다.
   > 그런데 아무 말도 하지 않았다.
   > 8초 뒤 전화는 끊겼다.
4. **식탁.**
   > 식탁 위에는 소주잔 두 개가 놓여 있었다.
   > 그날 밤, 그는 누군가와 술을 마셨다.
5. **불 켜진 창.**
   > 그가 숨지고 두 시간도 더 지난 새벽 1시.
   > 이웃이 그 집 안방에 불이 켜지는 것을 봤다.
6. **금고.**
   > 집 안에서 없어진 물건은 없었다.
   > 오히려 금고 안의 돈이 장부보다 500만 원 많았다.
7. **CCTV 화면.**
   > 마을로 들어오는 길은 하나뿐이고, 그 길에는 CCTV가 있었다.
   > 그날 밤 찍힌 것은 오토바이 한 대.
   > 그 오토바이는 그가 숨지고 한 시간이 지나서야 마을을 빠져나갔다.
8. **질문.**
   > 당시 수사팀은 끝내 답을 찾지 못했다.
   > 하지만 기록을 다시 읽어 보면, 그때 수사에는 빈틈이 있었다.
   > 당신이 그날 아침 이 사건을 맡은 형사였다면.
   > 범인을 잡을 수 있었을까?
9. **2008년 12월 25일 오전 10시, 하송리.** 화면이 바래며 전환.
   > 신고 들어온 지 한 시간.
   > 현장은 아직 그대로다.

컷신의 물음표 여섯 개는 게임 화면의 **의문 수첩**에 그대로 남는다(6.1절).

### 4.4 당시 수사는 왜 실패했나

하나의 그럴듯한 오판이 다음 오판을 불렀다.

1. CCTV 시각을 그대로 믿었다. 오토바이가 23:57에 나갔다고 봤다.
2. 그래서 "범인은 23:57까지 현장에 있었다"고 봤다. 새벽 1시의 불빛도 "범인이 아직 집 안에 있었다"로 읽었다.
3. 박동식은 23:25에 집에서 전화를 걸었고 아내도 23:20쯤 왔다고 했다. CCTV 시각 기준으로는 알리바이가 성립해 **수사선상에서 빠졌다.**
4. 거짓말이 드러난 아들 한재훈에게 수사가 몰렸다. 체포까지 했지만 통행권과 부검 소견으로 범행 시각에는 고속도로에 있었다는 것이 확인돼 풀려났다.
5. 아무것도 없어지지 않았다고 판단해 장부와 차용증 철을 맞춰 보지 않았다.
6. 피해자 손톱 밑 시료는 채취했지만, 비교할 용의자가 없어 대조하지 않았다.

**설계 원칙: 플레이어도 이 실수를 그대로 할 수 있어야 한다.** CCTV를 믿고 박동식을 빼는 것, 아들을 체포하는 것 모두 허용한다.

## 5. 수사 경로 — 빨리 잡는 길과 헤매는 길

### 5.1 빨리 잡는 길 (약 20~30분)

어느 하나만 일찍 떠올려도 범인 쪽으로 방향이 잡힌다. 범인을 **특정하는 것**과 **잡는 것(영장·증거)** 은 따로다. 특정이 빨라도 증거를 모으는 긴장은 남는다.

- **CCTV 시간 의심**: "CCTV 시계 맞아요?", "버스도 찍혔어요?" → 52분 차이 → 오토바이 실제 23:05 → 박동식 알리바이가 깨짐.
- **없어진 것 다시 확인**: "장부랑 차용증 맞춰 봐" → 박동식 차용증만 없음.
- **119 시각에서 출발**: 22:51을 범행 시각으로 잡고 장부 채무자 전원의 22:51 알리바이를 확인 → 박동식만 비어 있음.
- **손목 상처 관찰**: 박동식을 소환해 대화하다 손목을 보거나 물으면 "고양이가 할퀴었다".

### 5.2 헤매는 길 (약 60~90분)

- 아들의 거짓말이 드러난다 → 돈, 새벽 불빛, 몰래 온 것까지 다 맞아떨어져 보인다 → 체포 → 부검 소견과 통행권이 범행 시각에 고속도로였다는 걸 보여 준다 → **"그럼 대체 누가?"** (설계된 미궁 구간)
- 이 시점에서 의문 수첩의 ④⑤는 풀리고 ①②⑥은 남는다. 남은 물음표가 다음 방향을 가리킨다.
- 최만길(소주잔, 빚 숨김), 윤순자(땅 다툼)도 의심할 거리가 있지만 각각 확인 가능한 알리바이로 정리된다.

### 5.3 결정적 증거 (송치에 필요한 것)

| 증거 | 얻는 방법 |
|---|---|
| 손톱 밑 피부 DNA ↔ 박동식 | 박동식 구강세포 채취 (동의 또는 영장) → 국과수 대조 (게임 시간 3일) |
| 난로 재 속 차용증 조각 | 수리점 압수수색영장 |
| 오토바이 실제 시각 23:05 | CCTV 시계 보정 |
| 22:51 알리바이 없음 | 아내 진술 "11시 20분쯤" + 보정 시각 |
| 자백 | 위 증거를 들고 추궁 |

## 6. 게임 구성

### 6.1 화면 구성

| 영역 | 내용 |
|---|---|
| **의문 수첩** | 컷신의 물음표 여섯 개. 풀리면 해결 도장과 한 줄 설명. 플레이어가 직접 의문을 추가할 수도 있다. 이 게임의 진행 막대 역할 |
| **수사 지시** | 자연어 입력 + 분류 메뉴(현장 / 기록 조회 / 감정 의뢰 / 탐문 / 소환 / 영장). AI 없이 메뉴만으로도 모든 조사가 가능 |
| **자료함** | 지금 게임의 자료함 그대로 |
| **관계자 목록** | 처음에는 초동 보고서의 인물들. "수사선상에서 제외" / "다시 올리기" |
| **조사실** | 소환한 사람과 대화. 지금의 자유 대화·추궁·진술서 시스템 |
| **지도** | 하송리 지도: 피해자 집, 정미소, 하역장, 마을 입구 CCTV, 저수지 둑길, 박동식 수리점, 이웃집 |
| **수사 일지** | 날짜와 지금까지 한 일 |

### 6.2 "해 볼 수 있는 것" 목록 — 자유도의 핵심

자유도는 AI가 아니라 **미리 준비한 답의 양**에서 나온다. 사람들이 떠올릴 질문을 최대한 모아 답을 정해 둔다. 아래는 일부다. 실제로는 60~80개를 목표로 한다.

| 플레이어가 떠올릴 질문 | 답 | 역할 |
|---|---|---|
| CCTV 없었어요? | 마을 입구에 1대. 오토바이 한 대가 23:27 들어와 23:57 나감 | 미스터리 강화 |
| CCTV 시계 맞아요? / 버스도 찍혔어요? | 21:50 버스가 22:42로 찍힘. 녹화기 시계가 52분 빠름 | **핵심 열쇠** |
| 다른 길로 들어올 수 있어요? | 저수지 둑길. 차 한 대 지나갈 폭. CCTV 없음 | 아들의 길 |
| 지문은요? | 저울추에서 지문 없음. 면장갑 섬유 | 막다른 길 + 작은 단서 |
| 발자국은요? | 눈 위에 없음. 하역장 바닥 흙에 운동화 자국 (눈 오기 전인지 알 수 없음) | 아들의 흔적 |
| 문 잠금은? | 디지털 도어락, 닫으면 자동 잠김. 출입 기록 기능 없음 | 밀실 해소 |
| 창문은? | 모두 안에서 잠김 | 막다른 길 |
| 다른 출입구는? | 정미소로 이어지는 실내 통로. 집 쪽 걸쇠가 풀려 있음 | 밀실 해소 |
| 눈은 언제부터 왔어요? | 기상대: 23:30 시작, 02:30 그침, 4cm | **핵심 열쇠** |
| 통화 기록은? | 15:20 아들 6분, 16:00 박동식 2분, 22:51 119 8초 | 두 사람의 같은 기한 |
| 119 녹음은? | 수화기 부딪히는 소리, 남자 목소리로 "놔" 한마디 (누구인지 판별 불가) | 미스터리 → 다툼 |
| 개는 안 짖었어요? | 이웃: 10시 반 넘어 짖었고, 1시에는 조용했다 | 새벽 방문자는 가족 |
| 부검은? | 단일 두부 타격, 사망 22~24시, 위 내용물로 마지막 식사 2시간 안팎 뒤 | 시간 범위 |
| 손톱 밑은? | 피부 조직 채취됨. 비교 대상 필요 | 결정적 증거의 씨앗 |
| 금고는? | 장부 1,200만 원, 실제 1,700만 원. 500만 원은 신권 띠지째 | 미스터리 → 아들 |
| 띠지 어디 은행이에요? | ○○은행 신림지점, 08.12.24 | 아들 특정 |
| 없어진 거 진짜 없어요? | 장부 채무자 7명, 차용증 철 6장. 박동식 것 없음 | **핵심 열쇠** |
| 법무사 예약? | 26일 오전, 박동식 담보 땅 정리 건 | 박동식 동기 |
| 아들 어제 어디 있었대요? | "서울 집에서 잤다" | 거짓말 |
| 고속도로 기록은? | 통행권: 21:28 서울 요금소 진입 → 00:31 남오IC 진출, 01:52 남오IC 다시 진입. 남오IC에서 오면 저수지 둑길이 지름길 | 아들의 실제 동선. 22:51에는 고속도로 위 |
| 박동식 오토바이는? | 짐받이에 노란 공구함 | CCTV와 연결 |
| 박동식 손목? | 긁힌 상처. "고양이가" | 결정적 증거로 연결 |
| 마을에 고양이 있어요? | 박동식 집에는 고양이 없음 (아내 진술) | 거짓말 깨기 |

준비하지 못한 질문에는 AI가 "그건 기록에 없다", "그 시대에는 할 수 없다", "해 봤지만 나온 게 없다" 중 맞는 답을 짧게 한다. 새 사실은 만들지 않는다. AI가 없으면 비슷한 항목을 추천한다.

### 6.3 시간 — 부드러운 압박

- 조사에는 게임 속 시간이 든다. 탐문 몇 시간, 통화 조회 하루, 국과수 감정 2~3일.
- 행동 횟수 제한은 두지 않는다. **떠오르는 것을 다 해 보는 자유가 우선이다.**
- 대신 날짜가 흐르고, 끝의 평가에 걸린 날짜가 반영된다.
- 강제 압박은 하나만 둔다. 체포하면 48시간 안에 구속영장을 받거나 풀어 줘야 한다. 아들을 체포했을 때 이 압박이 미궁 구간의 긴장을 만든다.

### 6.4 소환과 영장

- 관계자를 소환하면 조사실에서 대화한다. 처음에는 참고인, 근거가 쌓이면 피의자로 전환(태도가 바뀐다).
- 깊이 대화하는 인물은 4명: 한재훈, 박동식, 최만길, 윤순자. 나머지는 짧은 답만 있다.
- 영장(압수수색·체포·구속·DNA 채취)은 근거 자료를 골라 신청한다. 엔진이 근거 조합으로 판정한다.
- AI를 쓰면 플레이어가 쓴 소명 문장을 판사 역 AI가 읽고 기각 사유를 말로 돌려준다. 판정 자체는 엔진이 한다.

### 6.5 송치와 끝 컷신

송치 의견서: 범인, 범행 시각, 흉기, 그리고 의문 수첩 여섯 개의 설명.

| 결말 | 조건 | 내용 |
|---|---|---|
| 해결 | 박동식 송치 + DNA 또는 차용증 조각 + 자백 | 2026년 문서고. "미제" 도장 위에 "해결". 의문 여섯 개가 한 장씩 다시 나오며 진짜 이유가 겹쳐진다. |
| 알았지만 증명 못 함 | 박동식 지목, 결정적 증거 없음 | "당신은 알고 있었다. 하지만 기록은 미제로 남았다." |
| 같은 실수 | 아들 또는 다른 사람 송치 | 억울한 사람의 그 뒤 한 줄. 가장 무거운 결말 |
| 수사 장기화 | 30일 안에 송치 못 함 | 당시 기록과 똑같이 끝난다 |

해결 결말의 **"의문 다시 보기"** 장면이 이 게임의 보상이다. 처음 컷신의 그림 위에 진실이 겹친다.
> 현관문은 잠겨 있었다.
> 도어락은 문이 닫히면 저절로 잠긴다.
> 눈은 그가 떠나고 25분 뒤에 내리기 시작했다.

### 6.6 AI의 역할 (필수 아님)

| 역할 | AI 있을 때 | AI 없을 때 |
|---|---|---|
| 수사 지시 해석 | 자연어 → 준비된 조사 항목 | 분류 메뉴에서 고름 |
| 조사실 대화 | 자유 대화, 지금의 검사·판정 체계 | 질문 목록에서 고름 |
| 준비 안 된 질문 | 짧게 "기록 없음/불가/결과 없음" | 비슷한 항목 추천 |
| 영장 소명 | 판사 역이 기각 사유를 말로 | 근거 조합 판정만 |
| 의문 수첩에 직접 추가한 의문 | 준비된 의문과 연결 | 준비된 의문에서 고름 |

## 8. 구현 단계 (브랜치 `cold-case`)

| 단계 | 내용 |
|---|---|
| 1 | 사건 설정집 확정 (이 문서 4절을 지금 설정집 수준으로 상세화) |
| 2 | 조사 항목 카탈로그와 의문 수첩 엔진, 메뉴만으로 끝까지 플레이 가능하게 |
| 3 | 컷신 컴포넌트, 시작 컷신 |
| 4 | 관계자 목록·배제, 소환, 게임 속 시간 |
| 5 | 깊은 인물 4명 대화 (지금 대화 시스템 연결) |
| 6 | 영장, 송치, 결말과 "의문 다시 보기" |
| 7 | AI 지시 해석과 준비 안 된 질문 처리 |

2단계에서 **AI 없이 메뉴만으로 끝까지 풀리는지** 먼저 확인한다. 재미의 뼈대는 AI가 아니라 사건과 조사 항목에서 나와야 한다.

## 9. 확인이 필요한 사실 (고증)

- 2008년 시골 단독주택의 디지털 도어락 보급과 자동 잠금 기능
- 2008년 군 단위 방범 CCTV 설치 여부, 녹화기 시계 오차가 흔했는지
- 2008년 고속도로 통행권에 찍히는 정보 (진출입 시각·IC)
- 2008년 국과수 손톱 밑 시료 DNA 대조 소요 기간
- 119 무언 신고 처리 절차와 녹음 보존

## 10. V1과 V2 비교 리뷰

### 10.1 한눈에

| 기준 | V1 금 트로피 2009년 이식 | V2 하송리 정미소 사건 |
|---|---|---|
| 첫 물음표의 양 | 1~2개 (죽은 사람의 문자, 한 사람 지문) | 6개, 서로 모순되어 보임 |
| "직접 해 보기" 자유도 | 낮음. 원래 문서를 순서대로 여는 구조라 질문 범위가 좁다 | 높음. 질문을 떠올리는 것 자체가 수사 |
| 미궁 경험 | 중간. 민아 의심 구간 | 큼. 아들 체포 → 풀려남 → "그럼 누가?" |
| 빨리 잡는 길 | 거의 없음. 증거가 순서대로 열려야 함 | 4갈래. 어느 하나만 떠올려도 방향이 잡힘 |
| 떡밥 회수의 쾌감 | 중간. 문자 조작 하나가 크다 | 큼. 여섯 개가 하나씩 평범한 이유로 풀림 |
| 납득감 (우연과 정보 부족) | 낮음. 핵심인 예약 문자는 범인의 의도적 조작 | 높음. 범인이 만든 이상한 점은 거의 없음 |
| 이미 아는 사람 | **지금 게임 플레이어는 범인을 안다** | 새 사건 |
| 제작량 | 적음 (자료·대화 재사용) | 많음 (사건, 그림 20장+, 조사 항목 60~80개) |
| AI 의존 | 대화 중심이라 높음 | 메뉴로도 끝까지 가능 |

### 10.2 V1의 한계

- 금 트로피 사건은 "문서와 진술을 대조하는 게임"으로 설계됐다. 수사 게임으로 옮겨도 "CCTV는?", "다른 길은?" 같은 질문을 받을 사건 구조가 없다. 원래 설정집 1절에서 CCTV·목격자·사진 증거를 일부러 막았다.
- 핵심 미스터리(예약 문자)가 범인의 의도적인 조작이다. 이번에 원하는 "우연과 정보 부족" 방향과 반대다.
- 지금 게임을 해 본 사람에게는 반전이 없다.
- 장점: 이미 검증된 대사·판정 체계와 자료가 있어 빨리 만들 수 있다.

### 10.3 V2의 위험과 대책

| 위험 | 대책 |
|---|---|
| 우연이 너무 많다고 느낄 수 있다 | 진짜 우연은 두 가지뿐이다(눈 내린 시각, CCTV 시계). 두 방문이 같은 밤인 것은 피해자의 같은 기한 통보 때문이고, 나머지는 평범한 생활이다. 결말의 "의문 다시 보기"에서 이 인과를 보여 준다. |
| "눈 위 발자국 없는 밀실"은 추리물에서 익숙해 트릭을 기대하게 한다 | 일부러 트릭이 아니다. 기상 기록을 1일차에 쉽게 얻을 수 있게 해 "아, 그냥 나중에 내렸구나"를 빨리 준다. 익숙한 기대를 깨는 것 자체가 이 게임의 성격을 알려 준다. |
| 빨리 잡는 길이 너무 쉬워 10분 만에 끝날 수 있다 | 특정과 증거를 나눈다. 박동식을 일찍 짚어도 DNA(3일)·압수수색이 필요하다. 의문 수첩의 나머지를 풀지 않으면 해결 결말의 보상이 줄어든다. |
| 준비 안 된 질문에 답이 허술하면 자유도가 깨진다 | 플레이 테스트로 실제 질문을 모아 항목을 늘린다. 지금 게임의 플레이 로그 수집 체계를 그대로 쓴다. |
| 제작량이 크다 | 메뉴만으로 끝까지 되는 뼈대를 먼저 만들고, 그림·AI는 뒤에 붙인다. |
| 깊은 인물이 4명이라 대화 규칙 작업이 늘어난다 | 지금 `talkRules` 형식을 그대로 쓴다. 숨기는 단계가 있는 인물은 박동식·한재훈 둘뿐이다. |

### 10.4 결론

**V2를 추천한다.** 원하는 경험(물음표 가득 → 직접 확인 → 미궁 → 가닥 → 납득)에 맞게 사건을 처음부터 설계했다. V1은 다른 장르를 위해 만든 사건을 옮기는 것이라, 구조를 아무리 바꿔도 자유도와 납득감이 한계에 걸린다.

V2에서 가장 먼저 확인할 것은 **메뉴만으로 플레이했을 때 재밌는가**다. 사건 설정집과 조사 항목 카탈로그를 먼저 만들고, 종이 시제품처럼 빠르게 한 판 돌려 본 뒤 그림과 AI를 붙인다.
