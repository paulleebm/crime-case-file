## 1. 처음 주는 정보

### 1.1 원칙

- **물음표는 많이, 답의 실마리는 겉으로만.** 컷신과 첫 회의 자료는 "무엇이 이상한지"만 보여 준다. "왜 이상한지"를 풀 자료는 하나도 주지 않는다.
- **당시 수사팀의 가설을 손에 쥐여 준다.** 반장의 브리핑은 백씨 집안 입막음설이다. 플레이어가 그 가설을 따라가는 것이 가장 자연스러운 첫 흐름이 되게 한다.
- **문은 다섯 개 열어 둔다.** 처음 자료 안에 서로 다른 방향의 실마리가 다섯 개 있어야 한다(3절).

## 3. 실마리 지도 — 문 다섯 개

처음 자료 안에 있는 다섯 방향의 실마리. 어느 문으로 들어가도 결국 펜션에 닿게 설계했다.

| 문 | 처음 실마리 | 따라가면 | 펜션까지 거리 |
|---|---|---|---|
| ① 바다 | E03 "마른 방바닥의 익사" | 부검 전문 → 방파제 → 최말순 → 통화 기록 | **가장 짧다** (3~4단계) |
| ② 112 | E05 요약 | 원본 녹음 → "그 집 식구" → 뺑소니 피해자 이름 → 문경자 | 짧다 (3단계) |
| ③ 사진 | E04 세단 사진 | 차고 대조 → 공업사 → 백씨 부자 → 알리바이 → 막힘 → ② | 길다 |
| ④ 돈 | E04 봉투 두 개 | 띠지 → 두 계좌 → 백승철·이도현 → 둘 다 알리바이 → 막힘 → ② | 길다 |
| ⑤ 보험 | E06 재혼 | 윤희 → 카드 → 이도현 → 주유소 → 위장 사망 → 강릉 알리바이 → 막힘 → ② | 가장 길다 |

③④⑤는 각자 **덤 사건 하나씩을 풀어 주고** 막힌다. 막히는 곳에서 반장 힌트가 ②로 이끈다(설정집 14.2).

```
 ③ 사진 ─┐                         ┌─ 뺑소니 해결(덤)
 ④ 돈  ──┼─▶ 백승철 ─▶ 알리바이 ──┤
         │                         └─ 막힘 ─┐
 ⑤ 보험 ─┴─▶ 이도현 ─▶ 알리바이 ── 위장사망·은폐 해결(덤)
                                    └─ 막힘 ─┤
                                             ▼
 ② 112 원본 ──▶ "그 집 식구" ──▶ 뺑소니 피해자 = 문태호 ──▶ 펜션
 ① 바다 ──▶ 부검 전문 ──▶ 방파제 ──▶ 최말순·통화 ─────────▶ 펜션
                                                             │
                     지아 추궁 ──▶ 경자 거짓 자백 ──▶ 빈틈 ──▶ 지아 자백
```

## 4. 시나리오

### 4.1 시간 계산의 근거

**보정 기준**: 지금 게임 EP.01 실제 플레이 약 25분, 면담 질문 10회 + 수사팀 요청 4회 + 힌트 2회([2026-10-17 라이브 리뷰](playtest-2026-10-17-live/review.md)). 질문 하나에 읽기·입력 포함 약 1.5~2분.

| 행동 | 실제 분 | 근거 |
|---|---|---|
| 시작 컷신 | 2.5 | 8장 × 약 20초 |
| 첫 회의 자료 7종 | 5 | 문서 7개 × 40초 |
| 기록 조회·감정 요청 1건 (입력 + 결과 읽기) | 1~3 | 지금 수사팀 요청과 같은 수준 |
| 탐문 1건 (짧은 인물) | 1.5~3 | 질문 1~2개 |
| 깊은 인물 조사 1회 | 5~8 | 질문 3~4개 |
| 조사실 결정적 장면 | 15 | 질문 7~8개, 장면 전환 |
| 영장 신청 | 3 | 근거 고르기 + 문장 |
| 하루 마치기 | 0.3 | 버튼 + 아침 보고 |
| 송치 의견서 | 6 | 지금 보고서와 같은 수준 |
| 결말 컷신 | 3 | |
| **생각 시간 배수** | 1.15~1.35 | 막힘·되읽기. 빠른 플레이어 1.15, 헤매는 플레이어 1.35 |

게임 속 시간: 근무 09~21시, 감정·조회 결과는 달력 시간으로 기다린다(설정집 10절의 비용).

### 4.2 시나리오별 흐름

#### S1 바다에서 출발 (최단, 명탐정)
"방에서 익사? 어디서 빠졌지?"를 처음부터 묻는 플레이어.
부검 전문 → 부검의 "건진 뒤 숨졌을 수도" → 방파제 수색(혈흔·슬리퍼) → 옆집 최말순에게 **소리**를 물음 → 지아·경자 통화 기록 → 계모임 → 별채 물 얼룩 → 지아 조사 → 피의자 전환 → 경자 거짓 자백 → 빈틈 → 지아 자백.
- 아하 순간: "건진 사람이 있다." → "여자애 목소리."
- 남는 것: 의문 1/7만 풂. 위장 사망·돈·카드는 모른 채 끝난다. 해결 결말이지만 "의문 다시 보기"에 빈칸이 많다.

#### S2 112 녹음에서 출발
반장 가설로 백승철을 한 번 만나 보고, 알리바이를 확인한 뒤 "녹음 원본"을 듣는 플레이어.
"그 집 식구들한테 먼저" → 뺑소니 기록의 피해자 이름 → 문경자 → 펜션 → 현장 재확인 → 방파제 → 최말순(처음엔 수상한 사람만 묻고 헛걸음) → 통화 → 지아·경자 → 압수수색 → 일기장 → 결정적 장면.
- 아하 순간: "그 집 식구가 펜션 식구였다."
- 남는 것: 의문 2/7.

#### S3 당시 수사를 따라감 (권장 흐름, 전부 풀기)
반장 가설을 끝까지 판다. 백승철 → 띠지 → 이도현 → 위장 사망 → 뺑소니 해결 → 이도현 은폐 해결 → **"다 알리바이가 있다"** (미궁) → 112 원본 → 펜션 → 결정적 장면.
- 아하 순간이 다섯 번: 위장 사망 / 두 봉투는 서로 다른 사람 / 새 남편은 알고 있었다 / 뺑소니 피해자가 지아 아빠 / 그 집 식구.
- 남는 것: 의문 7/7, 덤 사건 3개 모두. 대신 방파제에 늦게 가서 비 때문에 혈흔 DNA는 놓친다(다른 근거로 충분).

#### S4 보험 쪽부터 (이도현에 집착)
재혼 그림이 수상해서 이도현부터 판다. 윤희 → 카드 → 주유소 CCTV → 이도현 거짓말 → 위장 사망 → 강릉 알리바이 → 112 → 펜션.
- 남는 것: 의문 6/7(천장 돈의 백승철 쪽을 안 봄), 덤 2개.

#### S5 할머니 자백을 믿음 (오답)
지아를 피의자로 돌리자 경자가 자백한다. 플레이어가 "할머니였구나" 하고 송치.
- 결말: 할머니의 거짓 자백. 결말 컷신이 22:15의 방파제를 보여 준다.
- 이 결말은 **두 번째 판을 부르는 결말**이다.

#### S6 백씨 입막음설 고집 (오답)
뺑소니와 이도현 은폐까지 다 밝히고, 알리바이를 무시하고 백승철을 송치.
- 결말: 엉뚱한 사람.

#### S7 지아를 직감 (근거가 뒤따라옴)
마을 탐문에서 "지아와 친했다", 담임에게서 "긴소매"를 듣고 지아를 먼저 의심. 근거 없이 지아·경자를 만나 막히고, 뒤늦게 부검·방파제로 돌아간다.
- 남는 것: S1과 같지만 헛걸음이 있다.

## 5. 진단

1. **너무 길다.** 지금 게임은 25분이다. 새 사건은 최단 78분, 권장 흐름 230분(약 4시간)이다. 한 번에 앉아서 끝내기 어렵다.
2. **시간을 먹는 건 깊은 조사다.** S1의 78분 중 조사실이 약 45분이다. 특히 마지막 네 번(지아 추궁 → 경자 거짓 자백 → 빈틈 → 지아 자백)이 각각 따로 소환이라 28분이다.
3. **최단 경로는 의문을 1개만 푼다.** 결말은 해결인데 "의문 다시 보기"가 비어 있다. 빠르게 푼 사람이 덜 보상받는다. (반영 후: 지아 자백으로 Q1·Q4가 "진술로 확인"이 되어 1개 + 진술 2개)

5. 오답 결말(S5·S6)이 90분대라, 한 판을 길게 하고 틀리면 허탈할 수 있다.

## 6. 조정안

### 6.1 결정적 장면을 조사실 한 장면으로 (가장 효과 큼)

지아를 피의자로 돌리는 조사에 **경자가 동석해 있으면**, 그 자리에서 경자가 "내가 밀었소!" 하고 끼어든다. 플레이어가 그 자리에서 빈틈을 대면, 할머니를 보던 지아가 "할머니 아니에요"라고 무너진다.
- 네 번의 소환(28분)이 한 장면(15분)이 된다.
- 연출로도 낫다. 할머니가 손녀를 감싸고, 손녀가 할머니를 감싸는 장면을 **한 방에서** 본다.
- 경자를 동석시키지 않았다면 지금처럼 따로 소환으로 진행한다(선택의 의미가 생긴다).

### 6.2 위장 사망 서류를 한 번에

해경 실종 기록·보험 서류·실종선고 기록을 "위장 사망 관련 서류 다 가져와"로 한 번에 받게 한다. 지금 게임의 묶음 요청과 같은 방식.

### 6.3 백준혁을 짧게

백준혁 소환을 빼고, 공업사 장부 + 백승철 2차 조사로 뺑소니 덤 사건이 풀리게 한다. 원하면 소환할 수 있지만 필수는 아니다.

### 6.4 자백이 의문을 풀어 준다

지아 자백에서 "아저씨가 다 말했어요. 원래 이름도, 바다에서 죽은 척한 것도, 그 집에서 돈 받은 것도"가 나오면 Q1·Q4를 "진술로 확인"(반쯤 풂) 상태로 바꾼다. 결말에서 "진술로만 확인함"과 "증거로 확인함"을 나눠 보여 준다. 빠른 플레이어도 이야기 전체를 듣고, 완벽주의자는 증거로 채울 이유가 생긴다.

### 6.5 반영 결과

- 2026-10-23 6.1~6.4를 설정집 1.2에 반영했다(9.5 결정적 장면, TD-R19 서류 묶음, 백준혁 소환 선택, 의문의 "진술로 확인" 상태).
