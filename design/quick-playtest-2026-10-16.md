# 배포판 빠른 1회 플레이 점검

- 대상: https://crime-case-file.firebaseapp.com/ (동일 Firebase Hosting의 공식 별칭)
- 환경: 데스크톱 1920×1080, 실제 배포판 AI 응답 사용
- 기존 web.app 저장을 덮어쓰지 않고 별칭에서 신규 사건으로 진행했다.
- 사건 내용을 이미 알고 진행한 기능 중심 점검이며, 초심자 난이도 평가는 아니다.
- 코드 수정·배포는 하지 않았다.

## 결과

신규 시작 → 세 용의자 면담 → 수사팀 복합 요청 → 자료 22건 확보 → 근거 수집·드래그 첨부 → 진술 정정·자백 → 최종 제출 → 해결 → 진상 해설·후일담까지 완료했다. 범인 선택 및 서술 문항은 모두 정답으로 처리됐다. 콘솔 오류 조회 결과는 0건이었다. 이번 경로에서 진행을 막는 오류는 발견하지 못했다.

## 발견 사항

### 1. 대화에서 생긴 시간 모순이 최종 진술서에도 남는다

- 문태준은 처음에 20:30 집무실에 들어가 회장에게 보고했다고 진술했다.
- 예약 문자와 시신 이동을 추궁하자 “제가 회장님과 직접 말을 나눈 건 8시 25분 통화가 마지막”이라고 답했다.
- 이 모순을 다시 지적하면 “제 표현이 부족했습니다. 8시 30분에 들어가 회장님을 뵌 건 맞습니다”라고 답했으나, 앞의 문장을 철회하지 않았다.
- 최종 자백 후 진술서에는 20:31 범행 전 다퉜다는 내용과 ‘직접 말을 나눈 것은 8시 25분 통화가 마지막’이 함께 남았다.
- 개선: 최종 자백 및 진술 정리 시 이전 파생 진술의 충돌을 검사하고, 틀린 문장을 삭제하거나 이전 주장으로 정정 표시한다. 의도된 거짓말과 AI의 우발적 모순을 구분해야 한다.

### 2. 수사팀의 접수 안내와 실제 진행 상태가 일치하지 않는다

- “트로피에서 검출된 지문과 혈흔, 닦은 흔적을 정밀 감정해 주세요”라고 요청했다.
- 수사팀은 “트로피 표면의 지문·혈흔 검사와 함께 … 인물 대조 감정도 진행하겠습니다”라고 응답했다.
- 이후 상태를 묻자 “트로피 표면의 지문·혈흔 검사는 아직 착수가 안 된 상태여서 지금 맡겠습니다”라고 답했다.
- 한편 인물 대조가 완료되면서 표면 지문 검사 자료도 함께 도착했다.
- 개선: 실제 접수된 작업 ID와 관련 자료의 확보 상태를 기준으로 접수·진행·완료 문구를 생성한다. 이미 관련 결과를 제공할 작업이 있다면 미착수라고 안내하지 않는다.

### 3. 자료가 늘면 핵심 조작이 사이드바 아래로 밀린다

- 자료 14건, 트레이 3개일 때 1920×1080에서도 트레이 하단과 ‘사건 재구성·제출’이 첫 화면에서 사라졌다.
- 사이드바를 내리면 접근 가능하므로 진행 불가는 아니지만, 증거 첨부와 제출을 할 때마다 별도로 스크롤해야 한다.
- 개선: 자료 목록만 독립 스크롤하고 근거 트레이와 제출 버튼은 하단에 고정한다.

### 4. 결과 알림이 힌트와 대화를 가린다

- 수사팀 결과 알림이 남은 상태에서 우상단 힌트를 열면 알림이 힌트 본문 앞에 겹쳤다.
- 용의자 답변 도착 알림까지 추가되면 오른쪽 대화 영역도 크게 가려졌다.
- 개선: 힌트와 결과 알림의 표시 위치를 분리하거나, 힌트가 열릴 때 알림을 접어 배지로 표시한다.

## 정상 확인 및 제한

- 여러 항목을 한 번에 수사 요청하는 흐름, 면담 중 다른 화면에서 답변을 기다리는 흐름은 동작했다.
- 근거 문장 클릭 → 트레이 → 대화창 드래그 → ‘근거 제시’ 전환 및 복수 첨부가 동작했다.
- 예약 문자 등록 기록과 동선을 연결해 최종 자백을 얻을 수 있었다.
- 트로피 스케치는 페이지 배경에 직사각형 테두리 없이 표시됐다.
- 후일담 하단 버튼은 이 데스크톱 화면에서 잘리지 않았다.
- 모바일·좁은 화면, 저장 복원, 오답 결말, 모든 질문 분기는 이번 점검 범위 밖이다.
- AI 면담별 응답 시간은 일관된 타이머로 측정하지 않아 수치를 제시하지 않는다.
