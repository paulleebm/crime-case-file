## 바꾼 것

1. 모든 모델: talk 프롬프트의 `[자료별 반응]`을 형사가 가진 자료만 넣고, 1칸(인물 설정)에서 3칸(형사가 가진 자료 뒤)으로 옮겼다. 처음 상태 기준 약 3,900토큰 줄어든다.
2. Haiku만 (`server/aiHandler.ts`, `SMALL_MODEL_CHECK`): 질문 바로 뒤에 짧은 점검 목록을 붙인다.
   - talk: record를 빠뜨리거나 말하지 않은 것을 넣지 않기, 결정적 자료 앞에서 인정하기, 말로 시인했으면 admit 채우기, 자백 뒤 경위.
   - desk: "조회하겠다/알려 드리겠다"고 하면 start 채우기, 결과를 물었는데 아직 맡지 않은 조사면 맡기.
3. Haiku만 (`SMALL_MODEL_EFFORT`): talk의 effort를 medium에서 low로. medium + 점검 목록은 생각이 길어져 23~45초 응답이 섞였다.

## 남은 문제 (Haiku 최종)

- 가끔 시각을 섞는다: 준서가 "8시 50분쯤 매입점에서 나와서 9시 15분에…"(실제로는 9시 15분까지 매입점에 있었다).
- 수사팀이 권하기만 할 조사까지 바로 맡는 경우가 있다(CCTV → 매입점 방문 대장, 태준 휴대폰 → 업무 연락·정산 자료). 동시 3건 한도를 먼저 채울 수 있다.
- 자백 장면은 여전히 7~14초 걸린다(Sonnet 5~9초).
- 기록 개수는 Sonnet도 실행마다 1~5개씩 흔들린다. 한두 번 실행으로 판단하지 않는다.

남은 차이: 대화의 느린 꼬리(자백 장면 7~14초, Sonnet 5~9초). Haiku 5.5는 생각 길이 상한을 받지 않고(effort·끄기만), 대화에서 생각을 끄면 자백을 놓쳐(29/34) 지금 설정이 최선이다.

### 바꾼 것
- 대화(talk): 점검 목록(기록·건넴·인정·말과 admit 일치·자백 뒤 경위) + effort low.
- 수사팀(desk): 점검 목록("맡겠다"고 하면 start, 결과를 물었는데 아직 안 맡은 조사면 맡기).
- 진술서(statement): 점검 목록(kind 구분, 정정 판단, 항목 배치, 인정 항목 확인) + 생각 끔. `[철회된 말]`은 대화에서 실제로 한 말만 was로 쓰게 했다(게임 데이터의 진술 문장을 대화에 없는데 "앞서 한 말"로 붙이던 문제 — Sonnet·sol도 겪었다).
- 코드(모든 모델): 인정한 거짓말이 없는 사람의 added는 claim으로, 같은 말을 정정으로 표시하면 claim으로 (`sanitizeStatement`).
- 캐시 경계: 칸 구성은 그대로 둔다. Haiku 대화 캐시 적중 약 93%, 1M당 캐시 읽기 $0.01이라 경계를 더 나눠도 비용 차이가 거의 없다. 대신 `[자료별 반응]`을 형사가 가진 자료만 3칸에 넣어 처음 입력 약 3,900토큰을 줄였고, 점검 목록은 캐시하지 않는 마지막 칸 뒤에 붙인다(답 직전에 읽히도록).

## 로컬 플레이에서 나온 두 장면 (2026-10-17)

1. 민아에게 "오늘 한 일 다 말해주세요" → 하루를 한 문단(15초)으로 쏟아내며 묻지 않은 "총지배인님도 보지 못했다", "화장실 문은 닫혀 있었다"를 말했다.
2. 태준을 증거 없이 말로만 추궁 → "8시 48분에 등록됐다는 기록을 보여 달라"며 숨긴 예약 시각을 먼저 말했다. 고치는 중에 같은 상황에서 대사로 자백해 버리는 경우(admit은 빈 채)도 나왔다.

### 원인과 수정
- 민아 설정의 집무실 장면이 하루 이야기 한가운데 사실로 적혀 있었다 → "집무실 안을 물을 때만 말한다"로 표시. 지시문 A: 하루 이야기도 큰 흐름 3~4문장, 방 안 모습·다른 사람 행적은 물을 때만(자백 뒤 경위는 예외).
- 태준 cover에 조건 없이 "8시 48분이면 나는 이미 나간 뒤였다"가 있었다 → "형사가 그 시각을 말하거나 기록을 보여 준 뒤에만". 지시문 18: 자료를 요구할 때 형사가 쓴 표현만.
- 코드 안전장치(`src/ai/talk.ts`, 모든 모델): ① `leakedTimes` — 아직 인정하지 않은 거짓말의 근거·숨긴 진실에만 있는 시각이 형사의 말·대화·가진 자료에 없는데 대사에 나오면 다시 받는다. ② `confessesWithoutAdmit` — 범행을 인정하기 전, 인정이 받아들여지지 않은 턴에 자백하는 말을 하면 다시 받는다.

## 힌트·채점 Haiku 시험 (2026-10-17)

`scripts/hint-grade-compare.ts`로 같은 입력을 두 모델에 넣었다. 실행: `REPS=3 TAG=이름 npx tsx scripts/hint-grade-compare.ts claude-haiku-5-5 claude-sonnet-5-5`. Sonnet을 다시 돌리지 않으려면 `BASE=design/model-eval-2026-10-17-talk/hint-grade_r1.json`을 붙인다.
- 힌트: 게임 상태 9개를 쓴다. 초반, 이미 물어본 것이 있는 상태, 조사 결과를 기다리는 중반 두 개, 시간 모순 장면, 후반의 근거 붙이기, 안 읽은 자료, 예약한 사람, 보고서다. 상태마다 3번씩 돌려 모두 153점이다. 규칙 검사는 safeHint, 금지 낱말, 이미 한 일을 되풀이하는지를 본다. 여기에 Opus 5.5가 모델 이름을 모른 채 세 가지를 심사한다: 누설하지 않는지, 다음 단계로 이끄는지, 이미 가진 것을 다시 요구하지 않는지.
- 채점: 보고서 6개를 쓴다(정답, 부분, 오답, 섞임, 지시 끼워 넣기·빈칸, 애매). 문항마다 판정(정답·세모·오답)이 Sonnet과 같은지 본다. 일치율은 실행 3번 × 3번을 모든 쌍으로 짝지어 센다.

| 시험 | Haiku 5.5 최종 | Sonnet 5.5 |
|---|---|---|
| 힌트 (153점) | 153 · 153 · 151 · 152 | 152 · 152 · 150 |
| 힌트 중앙값 / 최대 | 5.3~6.3초 / 9.3~11.6초 | 2.8~3.0초 / 5.5~6.7초 |
| 채점 판정, Sonnet과 일치 | 98.9% · 98.1% · 95.9% (같은 모델끼리 97~100%) | Sonnet끼리 97.8% |
| 채점 중앙값 / 최대 | 5.2~5.3초 / 9.3~11.1초 | 4.2초 / 6.3초 |

### 바꾼 것
- 힌트(hint): 점검 목록을 넣었다(`SMALL_MODEL_CHECK.hint`). 세기 문장보다 문장 수를 늘리지 않는다. hint 칸에 detail의 행동을 쓰지 않는다. 이미 들은 질문은 묻게 하지 않고 들은 말을 짚는다. "~인지 짚을 차례다"처럼 의심을 심는 문장을 쓰지 않는다. 기다리는 동안 사람별 질문을 지어내지 않는다. 안 읽은 자료는 제목만 쓴다. 이미 가진 자료나 진행 중인 조사를 다시 요청하게 하지 않는다. effort는 기본값 medium이다. low는 Sonnet만큼 빠르지만 의심을 심는 둘째 문장이 3~10점 꼴로 남았다. 다른 사건을 든 예시도 넣어 봤는데 다른 장면에 "보여 달라고 하자"가 번져 뺐다.
- 채점(grade): 점검 목록을 넣었다(`SMALL_MODEL_CHECK.grade`). 문항과 요점을 빠뜨리지 않는다(Haiku는 가끔 results에서 문항을 통째로 빠뜨렸다). 구간 안의 시각은 yes다. 요점의 행동을 나눠 맞춘다. "싸우다가"만 있으면 우발로 보지 않는다. 빠졌다고 본 행동은 답에서 다시 찾는다. 어긋남은 no다. "~라고 하면 틀린 답"이 붙은 요점은 답이 그렇게 썼으면 no다(Haiku는 코멘트에 "틀렸다"고 쓰면서도 yes를 매겼다). effort는 medium이다(`SMALL_MODEL_EFFORT.grade`). 2,000토큰 상한에서 Haiku 응답이 한 번 잘려 grade의 `maxTokens`를 4,000으로 올렸다. Sonnet은 500토큰 안팎이라 상한을 올려도 바뀌는 것이 없다.
- 실험용 환경 변수: `SMALL_EFFORT="hint=low,grade=medium"`.

### 설정 (힌트·채점 전환 뒤)
- `functions/.env`와 `.env.local`: `ANTHROPIC_MODEL=claude-haiku-5-5`만 남기고 `ANTHROPIC_TASK_MODELS`를 지웠다. 이제 모든 작업이 Haiku다. 한 작업만 Sonnet으로 되돌리려면 `ANTHROPIC_TASK_MODELS=hint=claude-sonnet-5-5`처럼 적는다.
- 위 "설정" 절의 `hint=…,grade=…` 줄은 이제 옛 설정이다.
